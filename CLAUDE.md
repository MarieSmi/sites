# Кликабельный прототип — 7 экранов

Прототип по макету Figma. Собирается как **один самодостаточный HTML-файл**.

## Файлы

- `prototype.html` — единственный артефакт. CSS, JS, шрифты и картинки внутри файла.
  Снаружи — только Google Fonts и рамка демо [demo-frame](https://github.com/MarieSmi/demo-frame)
  (шапка и вспомогательная панель справа, jsDelivr по тегу).
- `.claude/build/` — исходники ассетов и `inject.ps1`, который вшивает их
  в `prototype.html`. Нужен, только если ассеты меняются; сам прототип
  самодостаточен и открывается двойным щелчком.
- `index.html` — переадресация на `prototype.html` (с `#/screen-N`) для корня Pages.
- Публикация — **только GitHub Pages**: https://mariesmi.github.io/sites/, из `main`
  при пуше. На Vercel не заливать: проект `sites` там от репозитория отвязан.
- `.claude/launch.json` + `.claude/serve.ps1` — локальный сервер на 8099
  для предпросмотра (`file://` не даёт браузеру подхватить вшитые шрифты).

## Карта переходов

- Стартовый — плашка «Биллинговые системы» → «Страницы». Других выходов нет:
  вкладок на стартовом экране не держим, это реестр сайтов, а не карточка сайта.
- Любой экран сайта — «‹ Биллинговые системы» → Стартовый
- Вкладка → одноимённый фрейм (экраны 2–7)

Тупиков нет: с каждого экрана есть выход.

## Как устроен файл

Разделы в `<style>` пронумерованы: ассеты → токены → оболочка → панель шагов →
иконки → общие блоки → и дальше по одному разделу на экран.

**Экран** — `<section class="screen">` внутри `#canvas`:

- `id="screen-N"` — адрес экрана, попадает в URL как `#/screen-N`
- `data-name="…"` — имя фрейма из Figma, показывается в панели шагов справа
- `data-chrome` — подставить общие блоки (меню, вкладки, правая панель)
- `data-sitebar` — шапка с кнопкой «Назад» и названием сайта
- `data-rail="…"` — набор кнопок правой панели, имена — из слоёв Figma
- `data-no-tabs` — не подставлять вкладки (стартовый экран)
- `data-active-tab="…"` — если активная вкладка не совпадает с id экрана
- все экраны лежат друг на друге, видимый помечен классом `is-active`

**Общие блоки** лежат в `<template>` в одном экземпляре и штампуются скриптом
при старте: меню, правая панель, вкладки, шапка сайта, график посещаемости
(`<div data-chart>` — место вставки). Иначе одна и та же разметка лежала бы
в файле по семь раз.

**Переход** — атрибут `data-goto="screen-3"` на любом элементе: кнопке, ссылке,
карточке, области. Обработчик один, делегированный, ничего дописывать не нужно.

**Рамка демо и масштабирование.** Шапку, холст и вспомогательную панель справа
расставляет модуль demo-frame (`DemoFrame.mount` в скрипте): холст 1600×900 —
в левом верхнем углу под шапкой, всё вместе вписывается в окно через
`transform: scale` с сохранением пропорций. В панели один сценарий
«Типовое представление», ссылка на макет и команда. Стрелки `←` `→` —
переход между экранами. Рамка частью макета не является.

## Правила работы с кодом

- Токены дизайна — только в `:root` через CSS-переменные. Хардкод цветов
  и отступов в правилах не допускается.
- Имена классов — от имён компонентов Figma (`Button/Primary` → `.btn--primary`).
- Разметка семантическая: `header`, `nav`, `main`, `button`, `a`. Не `div` на всё.
- Позиционирование — flex и grid по auto-layout из макета.
  Абсолютное позиционирование — только там, где оно есть в макете осознанно.
- Вёрстка сверяется с макетом замером, а не на глаз: `getBoundingClientRect`
  каждого блока против координат из Figma-метаданных.

## Шрифты и иконки

- **Inter** и **Roboto Mono** — Google Fonts, ссылкой.
- **cbuc-icons / cbuc-icons24** — иконочные шрифты Saby, вшиты как base64.
  Взяты с `cdn2.saby.ru/cdn/CbucIcons/1.5.9/`. Иконка = `<i class="icon">&#xE...;</i>`.
- **Maison Neue** — только логотип «saby design», вшита, оттуда же.
- Несколько иконок в открытых шрифтах Saby отсутствуют (`Accordion-Font`:
  «Виджеты», «Диск», гамбургер «Конструктора сайтов»; домик у «Главной») — вырезаны
  растром из эталонных рендеров Figma и вшиты как PNG.

## Что осталось за кадром

- Строки таблиц ниже 900 px не верстались: холст их обрезает.
  «Посетители» — строки 16–18, «Отклики» — с 12-й.
- Чекбоксы, сортировки и прочие контролы —
  статичные: интерактив сверх карты переходов не нужен.
