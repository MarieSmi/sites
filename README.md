# Кликабельный прототип — 7 экранов

Прототип конструктора сайтов Saby по макету Figma. Семь экранов, переходы между
ними работают. Собран как один самодостаточный HTML-файл.

## Как посмотреть

Открыть `prototype.html` двойным щелчком. Интернет нужен для шрифтов
с Google Fonts и для рамки демо (шапка и панель справа — модуль
[demo-frame](https://github.com/MarieSmi/demo-frame) с jsDelivr), всё остальное вшито в файл.

Если нужен локальный сервер (например, чтобы гарантированно подхватились
вшитые шрифты):

```
powershell -NoProfile -ExecutionPolicy Bypass -File .claude/serve.ps1
```

Дальше http://localhost:8099/prototype.html

## Публикация

Проект развёрнут на Vercel. `vercel.json` отдаёт `prototype.html` на корневом
адресе — иначе хостинг ищет `index.html` и отвечает 404.
`.vercelignore` не пускает на хостинг служебные файлы: `.claude/` и `CLAUDE.md`.

## Управление

| Клавиша | Действие |
|---|---|
| `←` `→` | переход между экранами |

Шапка и панель справа — служебные, частью макета не являются.

## Экраны

1. Стартовый экран — реестр сайтов
2. Страницы
3. Параметры
4. Статистика
5. Источники
6. Посетители
7. Отклики

С плашки «Биллинговые системы» на стартовом экране — переход на «Страницы».
Дальше переключение по вкладкам, кнопка «‹ Биллинговые системы» возвращает
в реестр.

## Что внутри

- `prototype.html` — единственный артефакт, 1,2 МБ
- `CLAUDE.md` — решения по проекту, карта переходов, node-id фреймов Figma
- `.claude/build/` — исходники ассетов и `inject.ps1`, который вшивает их
  в `prototype.html`. Нужен, только если ассеты меняются
- `.claude/serve.ps1` — локальный статический сервер на 8099
- `.claude/launch.json` — конфиг предпросмотра для Claude Code; путь к
  `serve.ps1` в нём абсолютный, на другой машине его нужно поправить
